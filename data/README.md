# Data storage policy

Acquire the dataset using `uv run --locked python scripts/download_data.py`.
Do not manually edit raw files. All contents of `data/` except this README are
ignored by Git, including raw and processed data.

```text
data/raw/uci447.zip                Original official UCI archive
data/raw/download.json            URL, acquisition time and SHA-256 provenance
data/raw/uci447/                   Original extracted archive contents
data/processed/cycle_metadata.csv Validated audit metadata, generated by inspection
data/processed/eda-summary.json   Aggregate descriptive Phase 2A evidence
data/processed/baseline-oof.csv   Development-only Phase 2B OOF predictions/metadata
data/processed/tuning-oof.csv     Development-only Phase 3A candidate OOF predictions
data/processed/tuning-runs/      Separate tuning progress/results/OOF journals
data/processed/final-test-predictions.csv  Phase 3B fixed-model reserved-test predictions
data/processed/inference-example.json     Phase 3B development-cycle inference example
```

The metadata CSV preserves all 2,205 cycles in source row order: `cycle_id` is a
one-based row number, followed by cooler condition, valve condition, pump leakage
(the target), accumulator pressure and stability flag. These identifiers and other
condition labels must not become prediction features. No unstable cycles are
removed. No prediction feature matrix is produced in Phase 1A. In Phase 2B,
deterministic features are computed only for development rows and retained in
memory; final-test feature rows and model predictions are not computed in Phases
2B/3A. Phase 3B first authorizes model feature/prediction access to the 339 reserved
test cases after manifest publication and the selected Pipeline's development fit.
Phase 3A reuses this extractor and the same saved memberships. Its candidate
predictions and journals use separate paths; baseline outputs stay unchanged.
Neither final-test nor outer-excluded IDs may appear in tuning prediction exports.
Phase 3B test predictions use their own output path and do not alter historical
baseline/tuning files. The 538 outer-excluded cases remain outside fitting and
evaluation. The saved complete model and metadata live separately under
`artifacts/models/phase3b-v1/`; no raw sensor samples are stored in the bundle.
The inspector removes any previous metadata CSV before auditing and publishes a
new CSV only after successful validation. Failed/interrupted audits do not leave
the old CSV at its normal path. Duplicate-cycle findings never filter raw data.

The cached ZIP is the independent source for extracted-file checksums after its
source-code digest pin is verified. Local manifest edits cannot authorize raw-file
changes. Rerunning the downloader safely recovers a missing extraction or manifest
from verified content; a malformed existing manifest or changed raw file is rejected.

Source: [UCI Condition monitoring of hydraulic systems, ID 447](https://archive.ics.uci.edu/dataset/447/condition+monitoring+of+hydraulic+systems).
Helwig, N., Pignanelli, E., & Schütze, A. (2015),
[DOI 10.24432/C5CW21](https://doi.org/10.24432/C5CW21).
Dataset license: [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).
When redistributing or adapting data, retain attribution, link to the license and
indicate changes. Raw sensor matrices remain unchanged; the generated CSV adds
column names and cycle IDs without filtering rows.
